# Sangwon Lee Academic Website

A simple static academic website designed for GitHub Pages.

## Files

- `index.html` — main website
- `styles.css` — site styling
- `profile.jpeg` — profile photo
- `Sangwon_Lee_CV.pdf` — downloadable CV

## Publish free with GitHub Pages

1. Create a GitHub account if you do not already have one.
2. Create a new **public** repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
3. Upload all four website files from this folder to the repository root.
4. In the GitHub repository, open **Settings → Pages**.
5. Under **Build and deployment**, select:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save. After a short wait, the site will appear at:
   `https://YOUR-GITHUB-USERNAME.github.io`

## Updating the CV

Replace `Sangwon_Lee_CV.pdf` with a newer PDF using **the same filename**.
The CV buttons on the website will continue to work without editing the HTML.

## Updating text

Open `index.html` in GitHub, click the pencil icon, edit the text, and commit the change.
